## CRW-ADV-001 reassessment

**Refuted.** The original report omitted the SN74LVC1G123 CLR rising-edge trigger mode.

Per TI SCES586E, March 2024:

- Table 4-1, pin CLR:  
  “Clear, Active Low; **also can operate as rising edge sensitive input if A is held low and B is held high.**”
- Detailed Description:  
  “The third method, the A input is low, the B input is high, and the clear (CLR) input goes high.”

For `U_RST2`:

```text
A  = GND       -> low
B  = 3V3_ADC   -> high during normal POR release
CLR= POR_N     -> low-to-high after supervisor delay
```

On normal startup, `POR_N` rising is a valid monostable trigger. Therefore `RESET_PULSE_H` is generated, `Q_RST1` turns on, and `ADC_RESET_N` pulses low as intended.

CRW-ADV-001 is removed as a defect. No redesign required for this item.
