# Unified schema-2 coarse P1 candidate review

The [candidate JSON](2026-09-24-p1-unified-coarse-candidate-sol.json) is a **research-only, incomplete** assembly of the five allocation proposals. It covers exactly 59 unique source nets in five allocations, with 65 selected native `ref.pad/net` witnesses and 25 proposed reservations. The [checker evaluation](2026-09-24-p1-unified-coarse-evaluation-sol.json) reports `INCOMPLETE`, five allocation rows, zero global errors, `routing_realized: false`, and `p1_accepted: false`. The USB row reaches reservation measurements; the other four correctly stop at the checker’s source-region locality gate. None of these fields is a P1 acceptance receipt.

The bound saved board is `/tmp/crow-usb-coarse-sol/projects/crow-usb-carrier-v1/04_kicad/crow_carrier.kicad_pcb`, SHA-256 `18e55f44d5c1a8f7a7dd050e12ca451f6e08932b8c79893a0ad74e3b18be861b`. It has 569 footprints and was generated in the USB coarse study from an isolated copy of the current floorplan (`4a457c731c204084a83aa817a29ca8fc8acc07097723adefedc296eb4db37b98`) and netlist (`f3b4e039a695eeec34843174e9430d4bbab5c65c4773ed3fa2a9998a18a0654d0e`). The canonical `04_kicad` board is absent. The artifact is not added to source; this review did not independently rerun a bit-for-bit regeneration. The contract independently hashes the saved board, P1 requirements, modular interfaces, USB4215 alias part, and floorplan. The fixed-reference authority is the source-owned 27-ref connector/hold-bank set, not the provisional XU, USB, PLL, or local electronic placements.

The source requirement now says `coarse_boundary_witnesses: required` and defers `exact_ref_pad_net_pockets` to P3. Its complete endpoint lists remain unchanged. This is the ADR 0011 P1/P2 boundary: the coarse checker samples native witnesses without making every floating local endpoint a P1 entrance condition.

This JSON is **not ready to become `coarse_geometry` in the source YAML**. Several generated witness bboxes bridge many millimeters from a selected pad to a proposed reservation edge: `U_ISO1.2` for `AUDIO_EN` spans about 122 mm, and a `R_ADC_1V8_OK_TOP.1` power witness spans about 85 mm. The checker now rejects such nonlocal bridges. A future virtual region-face witness would have to retain source/native pad identity while explicitly deferring the P2 pad-to-face obligation; widening physical pad bboxes would recreate the P1/P2 circularity. The current bboxes are diagnostic placeholders, not route or clearance evidence.

Power reservations were trimmed at shared signal-allocation boundaries for this coarse candidate: the three XU rail entries use `[199.825,91.325,201,108.675]` rather than the source power window's full `[185,91.325,201,108.675]`, and `N3V3_ADC` uses `[125,85,139.99,125]` rather than `[125,85,145,125]`. The full source power windows remain authoritative P2 current/return regions; the candidate only samples their handoff edges. The ADC analog allocation uses the two source demand net groups (nine nets each), correcting a draft ordering error. All reservations are inside the native outline with no cross-allocation same-layer positive-area overlap. The saved In1.Cu GND zone is unfilled, so continuous reference is not proved.

The evaluation was run with `p1_corridor_capacity.evaluate_coarse` using independently computed expected SHA-256 values for the contract, source, interfaces, USB alias file, and floorplan. It does not run route DRC, independent P1 review, local P2 placement admission, connector FULL, or filled-return proof. Follow-up should replace oversized witness placeholders, measure effective clearance and actual source-cell apertures on a saved filled board, and review power/current and shared signal crossings before any source geometry or P1 acceptance decision.
