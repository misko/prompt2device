## Other package findings

- `TI_TCA9406_DCU0008A_VSSOP8.kicad_mod` is a **separate correct** DCU variant for `U_ADC_I2C_XLATE`. Native 1 (-1.55,-0.75), 4 (-1.55,+0.75), 5 (+1.55,+0.75), 8 (+1.55,-0.75), size .85 × .30, pitch .5. Matches `02_parts/TCA9406DCUR/TCA9406-SCPS221G.pdf` PDF p33, TI 4225266/A example board layout. TSX `Tca9406DcuLand()` uses Y-up 1 (+0.75), etc., correct after Y conversion.
- `TQFP-128_14x14mm_P0.4mm_EP_XU316.kicad_mod` is **not mirrored**. Native 1 (-7.6625,-6.2), 32 (-7.6625,+6.2), 33 (-6.2,+7.6625), 64 (+6.2,+7.6625), 65 (+7.6625,+6.2), 96 (+7.6625,-6.2), 97 (+6.2,-7.6625), 128 (-6.2,-7.6625), 129 centre. `02_parts/XU316-1024-TQ128-C24/XM-014532-PC-v2.0.0.pdf` PDF p41, Fig.22 **top package drawing**, has 1 upper-left on left edge, 32 lower-left, 33 lower-left on bottom edge, 64 lower-right, then 65 right-lower, 96 right-upper, 97 top-right, 128 top-left. Native pitch .4 and EP 4.7 × 4.7 agree. TSX `XU316TQ128EPFootprint()` begins pin1 at the bottom edge in Y-up (a 90° starting rotation relative to native) but same hand. Native lead land is 1.475 × 0.25; TSX is 1.5 × 0.22, a small geometry divergence worth aligning at owning TSX/native source if parity is required. Fig.22 gives package lead width 0.13–0.23, not a recommended PCB land, so this alone is not a proven soldering error.
- `YXC_YSX321SL_3225_4Pin.kicad_mod` is correct. Native 1 (-1.1,+.85), 2 (+1.1,+.85), 3 (+1.1,-.85), 4 (-1.1,-.85), lands 1.4 × 1.2, matches `02_parts/X322524MOB4SI/YSX321SL.pdf` PDF p1 **top view** (4/3 upper, 1/2 lower) and top-view suggested layout pitch 2.2 × 1.7. TSX `YxcYSX321SLLand()` has opposite Y signs, correct Y-up.
- `SCTF_SX5M_5032.kicad_mod` is correct for active `Y_AUDIO`. Native 1 (-1.27,+1.15), 2 (+1.27,+1.15), 3 (+1.27,-1.15), 4 (-1.27,-1.15), size 1.8 × 1.3, matches `02_parts/SX5M24.576M20F30TNN/SCTF20215M027.pdf` PDF p4 **top view** and suggested solder-pad layout (2.54 × 2.3 centre pitch, 1.8 × 1.3 lands). TSX `Osc5032Land()` correctly uses reverse Y.
- `Abracon_ASFL1_5032.kicad_mod` appears correct but is not the currently selected audio oscillator. Native 1 (-1.27,+1.1), 2 (+1.27,+1.1), 3 (+1.27,-1.1), 4 (-1.27,-1.1), size 1.7 × 1.5. `02_parts/ASFL1-24.576MHZ-EC-T/ASFL1.pdf` PDF p2 top/outline drawing 4/3 above 1/2, recommended lands 1.7 × 1.5, centres 2.54 × 2.2.
- `Epson_FA238_3225_4Pin.kicad_mod` is a **dormant suspect**, not assigned in current schematic. Native 1 (-1.2,-.95), 2 (+1.2,-.95), 3 (+1.2,+.95), 4 (-1.2,+.95), size 1.2 × 1.1. `02_parts/FA-238-24.0000MD30X-W5/FA-238-24MHz.pdf` PDF p1 top view puts 1/2 lower, 4/3 upper, while recommended land drawing indicates size 1.4 × 1.2 and centre pitch 2.2 × 1.6. Thus native pin order is Y-mirrored and its land geometry differs. Repair if this retained alternative is ever selected; do not infer active PCB impact.
