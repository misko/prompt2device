# JLCPCB 1 oz USB differential candidate — 2026-09-22

## Selected fabrication stack

The selected candidate is **JLC04161H-7628G**, access id
`c9cc086852034b99bdf5d61bf940f3cc`. It was returned by JLCPCB's public
stackup API for rigid, 4-layer, nominal 1.6 mm, 1 oz outer and 0.5 oz inner
copper. JLC labels it `成品板厚1.63mm±10%` (finished thickness 1.63 mm ±10%)
and does not mark it `特殊` (special). This is a supported nominal-1.6-mm
selection, not a claim that the finished board is exactly 1.6000 mm.

L1-to-L2 dielectric height is therefore 0.5124 mm. The JLC calculator client
combines the three dielectric rows by an arithmetic mean, giving Er
`(4.4 + 4.4 + 3.91) / 3 = 4.2366666667`; it does not use a thickness-weighted
mean. The retained calculator client JavaScript had SHA-256 recorded in
`sha256sums.txt`; the raw template response is
`vendor-api/templates-4l-1p6mm-1oz.json`.

`JLC04161H-7628D` was rejected even though its single 0.2104 mm 7628 prepreg
would give a smaller pair: JLC marks it special and identifies its finished
thickness as 1.79 mm ±10%, so it is not the practical ordinary 1.6 mm choice.
The exploratory result for that unselected construction is retained with
`special-not-selected` in its filename to prevent accidental use.

separate exact request and produced the value above.

## Process and tolerance disposition

JLC's current rigid-board capabilities give 0.09/0.09 mm minimum trace/space
for multilayer 0.5 or 1 oz copper. The selected 0.410 mm width and 0.150 mm gap
are above those minima and the 0.150 mm project floor. The capability page
also gives ±20% ordinary track-width tolerance. That geometric tolerance is
not evidence that an uncontrolled board will remain at 90 ohms.

For a 90-ohm impedance value, JLC states ±10% controlled-impedance tolerance.
The fabrication requirement is therefore: select controlled impedance, name
JLC04161H-7628G, specify 90-ohm differential, retain the mask model, and accept
JLC's production-width adjustment only after updating the board rule before
release. The order stack echo/coupon target is 81–99 ohms. Board routing still
requires continuous In1.Cu reference, matching within the XU316 1 mm maximum
skew, and exact-board PCB/fabrication reviews.

The selected 1 oz process resolves the earlier 2 oz copper-clearance conflict,
but it does not prove the TPSM63603 thermal screen. The separate thermal work
must use a consistent efficiency premise: at 5 V/1.9 A, 70 °C ambient and
125 °C junction limit, 85% efficiency requires no more than 32.807 °C/W
for 1.67647 W loss; 88% requires 42.456 °C/W for 1.29545 W. Neither
is presently a demonstrated board thermal bound.
