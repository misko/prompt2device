# Crow P2 input/quiet-power placement mechanics (read-only audit)

**Conclusion.** The current generator already supports source-controlled local moves while freezing every unowned P1 footprint transform: use `placement.post_anchors` for the complete owned power cells. It runs *after* the unchanged global legalizer and *before* thermal-via emission and P-COLLIDE. The existing `tests/t1_generate_board.py` post-anchor fixture proves a named move leaves all other footprint positions unchanged. A three-seed diagnostic is a poor use of the two whole-block attempts: the input/quiet-power task owns 89 refs (20 input-buck, 69 quiet-power), 17 are fixed anchors (J_PWR and 16 hold capacitors), and 72 are movable; 60 owned refs currently have no explicit seed. The task has 47 measured layout rows, 41 failing on accepted P1. Three LDO edits cannot close supervisors, entry protection, precharge/hold, buck, and output groups, and changing pre-legalization seeds can alter unowned floaters because all footprints are obstacles to the global sorted legalizer.

## Exact cause of the stranded LDO parts

- Crow `03_src/floorplan.yaml` lines 179-190 declares `quiet_power` region x=25–75, y=105–134, overlapping the pinned hold-bank left x=24–74, y=113–137; right bank and middle strip forbid x=76–126, y=113–137. `U_LDO` has an explicit seed near (133,118), outside the quiet-power region and east of both banks. `R_LDO_ILIM` and `R_LDO_PG_TOP` lack seeds; both match the quiet-power pattern near lines 833-851.
- `generate_board_generic.py` `initial_pose` lines 1110-1135 treats a pattern `region` as only an **initial center**, not a legal final region. Both resistors start at region center (50,119.5), inside the forbidden left hold bank. `clear_at` lines 1910-1965 checks board edge, holes, three `forbid` rectangles, and every other footprint's box; it does not check pattern-region membership. `legalize` lines 1967-2006 visits refdes in sorted order, searches rings in 0.5 mm steps with 20° angles, and uses the first clear point. The two resistors therefore emerge near the west/north bank boundary: accepted P1 native centers are ILIM (72.6,111.3) and PG top (74.9,110.4), while U_LDO is (132.5,118.2). The saved policy audit measures U_LDO.5→R_ILIM.1 = 59.51/5.0 mm and U_LDO.6→R_PG_TOP.2 = 59.17/5.0 mm. This is an initial-pose/forbid/search interaction, not evidence the intended circuit wants those long nets.
- The quiet-power region does **not** stop either resistor from being explicitly placed near U_LDO east of x126. Conversely, the `forbid` rectangles are only legalizer filters; `post_anchors` bypasses them, so their final locations must be independently checked against bank bodies/courtyards.

## Supported controls and tradeoffs

1. **Recommended:** Keep all existing anchors, seeds, patterns, regions, forbids, `legalize` settings, netlist and library inputs unchanged. Add full `[x,y,rotation]` `placement.post_anchors` for the movable input/quiet-power refs that need coordinated repositioning. `build` calls `legalize()` then `apply_post_anchors()` then emits thermal vias and runs `P-COLLIDE` (`generate_board_generic.py` lines 672-683, 2008-2034). This preserves the exact baseline legalizer result for all unowned footprints; compare all 479 unowned transforms against board `b7b1e7c8…` and fail on any change. Build *complete* local cells against the 47-row target list before spending attempt 1; this should include the LT3045 input/output/programming neighborhood, Q_IN/F_IN/D_IN protection chain, Q_PRE/D_HOLD, U_PWR/U_AUDIO/U_DUMP/U_LDO_EN and their local passives, plus buck satellites. A prepared coordinate table is an engineering candidate, not a pass claim.
2. `placement.seeds` plus a `placement.keep` list can hold refs fixed, but `keep` only preserves their **initial** pose. To freeze unowned P1 placements that were legalized away from pattern centers, it would need an explicit pose for every unowned ref (roughly 479), with many source edits. Seeds also change the obstacle set seen by the sorted global legalizer, so without that catalog an owned seed change can move an unowned part. `placement.pin` is a glob allowlist for anchors and would unpin existing 27 anchors if used incompletely. This is not the minimal P2 source seam.
3. Moving region centers or adding `near` patterns is not a final-area constraint. `near` only resolves target **anchors**, not U_LDO's seed, and changing the broad quiet-power center would move many unrelated parts. New generator code is unnecessary for a bounded P2 trial.

**Required rechecks for `post_anchors`.** It applies after `run_asserts`, and a two-value entry silently sets rotation to 0; use three values and independently verify changed pad orientations/roles. It skips `clear_at`, so explicitly reject any moved footprint in hold-bank forbidden space, board-edge/hole violation, support/ADC intrusion, or corridor/capacity regression. P-COLLIDE catches pad overlap and courtyard overlap among fixed/post-anchored refs, but an unowned floating footprint is not in its fixed-courtyard comparison; retain native full-severity DRC, model/body/courtyard and placement preflight. Thermal vias are emitted from final pad geometry. Regrade exact 47 owned layout rows (6 keep-short, 41 adjacency), source-to-native pin/net parity, 27 anchors, all 16 hold poses, 568 model files, and the 479 unowned footprint transforms. The accepted P1 board remains immutable; a P2 board remains isolated, unrouted and non-promoted until all relevant gates close. FULL 19 physical targets still blocks P3/routing/P5 promotion/release/order.

No board was generated, source modified, or attempt consumed for this audit.
