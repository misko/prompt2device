# P1 graph checker prototype

`skills/kicad-pcb/scripts/p1_corridor_graph.py` is the first executable schema-2 topology screen. It is separate from the schema-1 straight-lane diagnostic and does not change a canonical board or P1 task. Its JSON contract binds SHA-256 digests of the saved native board, source P1 YAML, modular interfaces, and USB4215 part aliases; the CLI also requires independent expected hashes for the contract and those three source files. A `crow-p1` profile requires exactly 59 nets in five source coverage groups. The current source partition is USB 4, XMOS service 13, ADC timing 14, ADC analog 18, and power/mechanical 10.

Each allocation lists every source `ref.pad`, its expected native `ref.pad`, and net. Signal allocations additionally list pad pockets, copper-layer junctions, and two-port segments with assigned nets. The checker compares the source and modular-plan endpoint sets, applies the part-file J_USB aliases, verifies native pad/net/layer identity, checks each pocket and segment against the native outline, and requires every terminal of each net to be reachable in the declared graph. A pad on an endpoint footprint is only exempted from its own segment access; unrelated pads on that same footprint remain visible in `obstacle_pads`. This is an obstacle inventory, not a clearance result.

An edge connector pocket must stay on board and bind a named native footprint, drawing reference, native Edge.Cuts segment, local-to-board mouth transform, mouth offset/tolerance, and maximum body overhang. Ordinary off-board pockets and bodies are rejected. The power/mechanical group validates exact native terminal identities, including the 16 RJ45 CHASSIS pads in the corrected source, but its current/thermal and separation geometry remains open.

The tool always reports `status: INCOMPLETE`, `routing_realized: false`, and `p1_accepted: false`, returning a nonzero CLI exit. A `graph_valid: true` allocation means only that the declared terminals and topology passed this screen. Raw aperture capacity, effective net rules, pad-to-segment clearance, filled In1.Cu GND continuity, DRC, connector fit, and independent P1 admission are still required. No Crow graph geometry contract has been authored; the source's signal `geometry` remains null.

Validation: nine synthetic native-board tests cover a connected three-terminal branch, a missing branch, wrong USB alias, ordinary off-board pocket, layer-mismatched turn, retained same-footprint non-target pad, edge mouth/overhang registration, hash drift, and the live 59-net source partition. `python3 -m unittest skills/kicad-pcb/scripts/tests/test_p1_corridor_graph.py -q` passes; both new Python files compile.
