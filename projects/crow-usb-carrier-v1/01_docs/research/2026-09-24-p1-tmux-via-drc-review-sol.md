# Isolated TMUX4827 B2 via DRC diagnosis (read-only Crow source)

**Result: no canonical fix is ready.** The eight intentional U_ISO1..8 B2/GND vias are the entire remaining native DRC cluster after generating the actual route-rule sidecars. Merely enlarging their copper diameter to the current board minimum is not a legal repair: it clears eight diameter errors but worsens local pad clearance while leaving 152 violations. The original 293-violation comparator was run without `generate_rules_generic.py` and should not be used as the acceptance baseline.

## Reproduction and counts

Base subject is Terra's isolated `crow_carrier.kicad_pcb` (`ce589f8a4889854946ef9a1c234ed57de89bfbf220e60f72cd6d818734d8813e` before refill). I copied it outside the project, supplied the complete generated `.kicad_pro`/`.kicad_dru`, exact schematic and footprint-library table/path, then ran `kicad-cli pcb drc --severity-all --refill-zones --schematic-parity --all-track-errors --save-board --format json`. The saved base board SHA-256 is `28f33b87f767721bd16e2b59beeec83b0fc0d9561799b63048416559924fa2500e6f6`; JSON `/tmp/crow-baseline-rule-sol/drc.json` SHA-256 `7eaaab9f5d18ba4e1c7b2dc098801e40213fcd8c0d9ba687a39a705379ce6d8e`: **160 violations** = 80 clearance + 64 hole clearance + 8 via diameter + 8 annular width; 499 unconnected, zero schematic parity. All 160 local violations involve U_ISO1..8; each contributes six pad-pad and four pad-via clearance findings, eight hole-clearance findings, one diameter and one annulus finding. The 499 open connections remain separate un-routed diagnostic debt.

The source `thermal_vias.fields` makes one filled/capped Ø0.35/0.20 GND via at pad 5 of each 3×3 TMUX4827. Native settings instead demand Ø0.45 minimum via copper, 0.13 annulus and 0.25 copper-to-hole clearance. The same 0.4-mm pitch Ø0.25 perimeter lands have a physical 0.10-mm copper gap to the Ø0.35 centre via and 0.175-mm hole-to-pad copper gap. The retained exact-package coupon intentionally configures 0.10 clearance, 0.10 hole clearance, Ø0.25 via minimum and 0.075 annulus, passes its *coupon* DRC, and explicitly leaves vendor fill/cap/CAM/PCBA acceptance owed. The project source's normal netclass/board minima and coupon process are different rule envelopes. Per [KiCad's constraint documentation](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.pdf), a custom rule cannot undercut Board Setup absolute minima; a `.dru` exception alone cannot fix these four classes.

## Tested isolated source delta — rejected

Only in `/tmp/crow-via45-sol/projects/crow-usb-carrier-v1/03_src/floorplan.yaml`, I changed the eight U_ISO B2 `size: 0.35` values to `size: 0.45`, retaining `drill: 0.20`, GND ownership and capping/filling. `generate_board_generic.py` completed with 569 footprints and 14 explicit protected thermal vias, and `generate_rules_generic.py` emitted the normal route sidecars. On the same native DRC flags and complete footprint paths, post-save board SHA-256 is `1fbb0f4553650add6439b536121288502825859ea3fabaf21490c6ce1c3c9be3`, JSON `/tmp/crow-via45-sol/drc.json` SHA-256 `4b4030526c4960b8538787461d4c0fb730b0c8ea13fb3382a03b131b964675de`: **152 violations** = 80 clearance + 64 hole clearance + 8 annular width; 499 unconnected, zero parity. The via-to-neighbour copper gap fell from 0.10 to 0.05 mm, and the Ø0.45/0.20 annulus is 0.125 mm, still below 0.13. This delta preserves the GND drill path but worsens the physical copper separation; reject it.

## Required engineering choice

The exact B2 via-in-pad geometry conflicts with current board absolute minima; enlarging or moving that through-via within the 0.4-mm 3×3 array cannot satisfy both the current Ø0.45/0.13/hole-clearance constraints and the neighbouring balls. A governed advanced-package rule model would need to set board absolute minima at the qualified fabrication floor, then *restore* stricter ordinary via, annulus, pad/hole and net clearances through proven scoped rules; it must be tested with intentional negative fixtures outside each of eight B2 sites and checked against actual JLC fill/cap/CAM/PCBA capability. The 48 same-package pad-pad findings also need an exact package-local clearance disposition; unrelated copper must retain its current requirements. A different package/part or another proven grounding topology is the alternative. No board rule weakening, source diff, or P1 DRC acceptance is proposed until one path is proven.
