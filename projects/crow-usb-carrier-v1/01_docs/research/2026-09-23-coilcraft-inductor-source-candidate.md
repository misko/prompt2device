# Coilcraft stocked TPS62825 inductor source candidate

The three digital TPS62825 power-stage inductors use Coilcraft XFL4015-471MEC, JLCPCB C18221164, in this source candidate. TI SLVSEF9I Table 8-5 recommends electrical part XFL4015-471ME. Coilcraft Document 769 says the final C merely specifies 7-inch machine-ready reel packaging. The primary part rating is 0.47 µH ±20%, DCR 8.36 mΩ maximum at 25 °C, SRF 89 MHz typical, saturation 6.6 A at 30% inductance drop (25 °C), and 11.2 A at 40 °C temperature rise in the manufacturer's reference test. The existing 1.79 A peak screen is below these listed current figures. Typical DC-bias curve suggests ~0.44 µH at 1.79 A; it is not a guaranteed hot minimum. TI recommends approximately 20–30% Isat headroom and does not impose a numeric SRF minimum in its selection text.

Direct JLCPCB SMT endpoint returned 3,051 units on 2026-09-23 against 3 × 5 + 150 = 165 required. Refresh exact stock before order. Coilcraft's page-2 lands are 0.98 × 3.4 mm on 2.37 mm pitch, implemented independently in TSX and native KiCad footprint. Source pin 1 connects each SW node and corresponds to the marked start/short terminal, per Coilcraft's EMI note. This does not certify native placement, switch-loop escape, copper thermal rise, EMI, or TPS62825 output-filter stability. The base source has 2×47 µF on each rail, outside the TI Table 8-3 checked 100-µF column; the separately reviewed cap-bank candidate reduces each to 1×47 µF and must be composed before treating the LC matrix as checked. No capacitor source change is made here.
