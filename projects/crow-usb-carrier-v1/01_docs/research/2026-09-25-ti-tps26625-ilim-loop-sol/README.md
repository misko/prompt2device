# Bounded TPS26625 channel-8 ILIM signal-leg rejection

This packet tests **one** 0.20-mm `SPOKE_ILIM8` F.Cu→B.Cu→F.Cu route from `U_SPOKE8.7` to `R_SPOKE_ILIM8.1` on the immutable source-generated [input/output/return witness](../2026-09-25-ti-tps26625-output-loop-sol/README.md), board SHA-256 `28412ec5054d3b322ea03e37516aa969551beb1e2083b2fa0d2662863969dff4`. `probe.py` reconstructs the attempted copper in memory and replays the complete archived native `.pro`/`.dru`/POFV/V-PROCESS profile. No rejected board is retained. The 569 footprint pad/pose ledger, 27 fixed refs, input and output bypass traces, filled In1 GND return, and separate `SPOKE_RTN8` copper are preserved.

The existing U.6 GND pad and its F.Cu return at y=48.5 mm block a direct south escape from U.7; the nearby PowerPAD/RTN copper limits the west side. The attempted route leaves U.7 `(191.4,48.0)`, reaches a 0.60/0.30-mm through via `(191.95,47.95)`, travels on B.Cu to a second via `(191.825,50.2)`, then joins R(ILIM).1 `(191.825,51.0)` on F.Cu. The three signal centerlines total **3.605738 mm**. All attempted copper boxes stay inside source `analog_ch8` `[179,42,201,84]`; only the two endpoint footprints' full envelopes intersect the route boxes. Native connectivity does link the named ILIM pads, and the GND and RTN connected-pad sets remain disjoint.

**Reject:** the first via's native effective F.Cu copper is only **0.138243 mm** from `U_SPOKE8.8`, below the governed Default-netclass **0.150 mm** clearance. Its gap to the existing GND return is **0.150023 mm**. Full-profile DRC changes from **199 to 200 violations**, with exactly **one added clearance issue identity** (reported actual 0.1382 mm), zero removed issues, **499 unconnected items** on both boards, and no V-PROCESS failures. The failing route is not admissible, so the closed ILIM loop area is **undefined/null**, even though the two named pads touch in the rejected candidate. Existing R(ILIM).2→U.5/PowerPAD RTN returns do not cure the signal-via clearance.

This result rejects the one via-pair pose; it does not prove all ILIM routes impossible. A coupled support/return topology or placement recut is preferable to an unapproved narrow via/clearance exception, and must retain the source IN/ILIM adjacency, GND/RTN distinction, other local loops, thermal island, and ADC8N witness. No canonical, P1, or P2 promotion follows.
