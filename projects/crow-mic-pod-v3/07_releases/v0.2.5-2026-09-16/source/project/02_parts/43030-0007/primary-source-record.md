Accessed: 2026-09-01
Authority status: exact manufacturer product/tool facts; raw documents owed

- Molex extraction tool `11-03-0043`, instruction identity `HT60923A`

The contact supports 20, 22, and 24 AWG wire, up to 1.85 mm insulation outer
diameter. The full-cycle ratcheting hand tool supports 43030-0007 over that
wire range. Strip length is 2.54-2.92 mm. For 22 AWG the manufacturer tool
record gives conductor crimp height 0.83-0.93 mm, reference insulation crimp
height 1.58 mm and width 1.72 mm, and 35.6 N (8 lbf) minimum pull force.

Harness process for the first article:

1. verify Belden conductor construction and insulation diameter against the
   exact contact range;
2. strip 2.54-2.92 mm without nicking strands;
3. use only hand tool 63819-0000 and complete its ratchet cycle;
4. inspect conductor bellmouth/brush and insulation support;
5. measure crimp height on setup samples and perform the manufacturer's
   occasional destructive pull test, using 35.6 N minimum for 22 AWG;
6. insert until the contact locks in the exact cavity; tug-check each contact;
7. continuity-test 1-1, 2-2, 3-3, 4-4 with no cross-short;
8. use extraction tool 11-03-0043 only for rework and reject damaged contacts.

This record binds the selected hand process. It does not replace first-article
inspection or prove enclosure access.
