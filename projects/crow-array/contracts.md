# Crow public publication boundary

This project contains a separately identified public derivative of the sealed
Crow prototype, not a live design workspace or a replacement seal. `publication.py`
builds/verifies the explicit allowlist; `test_publication.py` exercises positive
and corrupt-package cases. `native_smoke.py` checks isolated 2D replot fidelity;
`publication-policy.json` binds reviewed derivative notices; `checks/**` retains
scoped publication/native results and `licenses/**` retains required notices.
`releases/**` contains only inventoried copies,
notices and generated handoff metadata. No vendor runtime or unlicensed document
may enter through recursive copying. The upstream local seal is read-only.

Repository MIT covers original content; copied KiCad library collections retain
their own license and notices. Publication does not close ordering holds.

`order-readiness/**` is a mutable, separately scoped purchasing continuation.
Its STATUS/journal owns current execution; no file there changes a sealed or
public release receipt. Observations and draft inquiries are not vendor approval.
