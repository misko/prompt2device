# Current source-bound mechanical and reference views

The current accepted native boards are copied before CAD inspection. The retained
immutable mechanical/reference algorithms are explicitly parameterized by the
new adapter with those exact copied bytes and hashes. They produce dimensioned
outline/NPTH views and complete per-reference pad locators under
06_build/recovery/first-run-d3-staging/mechanical1 and reference1.

There are 138 carrier and 31 pod reference cards, across nine and two A4 pages.
Native absolute +X/right, +Y/down coordinates and angles are retained; these
cards are supplementary lookup aids, not vendor rotations, true pad shapes,
body/fit models, tolerance guarantees or scaled manufacturing templates.
Use native assembly PDFs, exact population/BOM/CPL, maker drawings and all
complete LS43/LS33 instructions together. No actual inspection is implied.
