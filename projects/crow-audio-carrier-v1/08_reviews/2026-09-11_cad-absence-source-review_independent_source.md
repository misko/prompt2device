# Independent CAD-absence source judgment

## Verdict

The saved API evidence establishes a **snapshot-specific catalog-CAD absence**, not a transient HTTP 403: on 2026-09-11 at 19:24:45Z and 19:24:46Z, the exact public EasyEDA component URLs for `C3761431` and `C861313` returned HTTP 200 and the identical 60-byte JSON body `{"success":false,"code":404,"message":"Component not found"}` (SHA-256 `2e5c07eb9432f630b1c0fbaf02bcf601e7e9ddd0d3df5008254d90298764c1f2`). This proves only that the endpoint supplied neither footprint nor model for those codes at those observations. It does not prove a vendor pad fit, permanent global absence, allocation, or orderability. No additional request or retry was made in this review.

The documented procedure conceptually permits a true `NO-CAD` disposition after absence is independently proven, and requires a separate disposition for true missing CAD. It does **not currently implement** the requested native-body path: `native_representation.py` accepts only `reason: vendor_model_absent`, requires a nonempty fetched footprint hash, and `jlc_twin.py` skips the part before native-body retention when fetch returns `NO-CAD`. A narrow `vendor_cad_absent` branch is reasonable for a prototype **DO NOT ORDER** twin, but only after the source-copper findings below are closed and all ordinary physical gates remain active. This review is design advice, not implementation acceptance or order release.

Authority is the manufacturer-authored Littelfuse *1812L Series Surface Mount* PDF, revision GD 06/10/24, exact captured SHA-256 `a18b5ceec6d56cd31b20da55341ed1b35a48184f1f7fff8ca8bc6948cd8fb974`, public mirror `https://www.megastar.com/content/pdfs/1812L-Datasheet-Update.pdf`, with the original manufacturer endpoint recorded as `https://www.littelfuse.com/assetdocs/resettable-ptcs-1812l-datasheet?assetguid=ca5c80cb-504e-4a8a-8e74-0107520a1717`. The derived WRL is an honest maximum-envelope visual body: direct vertex extrema are `4.73 x 3.41 x 1.8` mm, centered in XY with Z from 0 to 1.8 mm. Its two 0.4 mm visual terminal bands are only the documented midpoint choice within E; they are not a contact-fit authority. The model choice is accepted as a conservative visual/clearance body with that limitation.

The present copper is not source-equivalent to the viewed pad figure. Its `1.125 x 3.4` mm lands at 4.275 mm pitch differ from the published `1.78 x 3.15` mm lands at 5.23 mm pitch: width −0.655 mm, height +0.25 mm, pitch −0.955 mm, inner gap 3.15 versus 3.45 mm, and outer span 5.40 versus 7.01 mm. Therefore `F1`–`F8` must not enter an accepted native representation on the current footprint.

The bounded source fix is a custom, hash-bound `1812L035/60` footprint derived from the viewed page-6 figure: two `1.78 x 3.15` mm pads, 3.45 mm inner gap (5.23 mm center pitch), F.Fab `4.73 x 3.41` mm for this maximum-body model, and an F.CrtYd that encloses the union of the 7.01 mm land span and 4.73 x 3.41 mm body with the project's explicit courtyard clearance. Re-run routing/clearance/DFM after replacing all eight footprints; do not infer acceptance from the generic 1812 name. An independent two-pin/net review must confirm each branch assignment. ## Minimal fail-closed contract

A new `reason: vendor_cad_absent` must be a closed-schema sibling, not a waiver or manual JLC-part reclassification. It should require exact LCSC code, exact MPN, explicit unique refs, `render_model_source: native`, and one or more immutable API receipts containing URL, observed time, transport status, response-body SHA/size, and parsed application code/message. Accept only the expressly enumerated absence response shape; reject HTTP/auth/rate-limit/unrecognized failures as `FETCH-FAILED`. Treat the receipt as time-bounded and automatically reopen the selection when a later successful fetch supplies any footprint or model.

Because there is no vendor footprint, the receipt must state `catalog_comparison: unavailable`; it cannot produce `PAD-GEOM`, `PAD-MISMATCH`, vendor residual, or vendor rotation PASS. Instead require hash-bound primary drawing pages/revision, native footprint, native model, generator/provenance, source board, reviewer/date/limitations, and a dedicated independent pin review receipt. `jlc_twin.py` must retain the part in the full CPL denominator and install the native body after a recognized `NO-CAD`, rather than `continue` past it. `NO-BODY` remains `9/9` for these requested refs and full-board `N/N` globally; absence, pad, and body findings remain separate.

Create two exact-ref registration groups: `F1`–`F8` together and `R_PWR_TOP` alone, each using `registration_datum: all_pad_centres`, `mount_side: front`, finite fit/courtyard tolerances, finite search margin, render size, and signed-side minimum fraction. Registration must use all physical pad centers, the independently authored F.Fab envelope, source body envelope, and actual copied model hash/transform. It must exercise 0/90/180/270 transform fixtures, front/back side coupons, and an intentionally inverted negative fixture. Require model-to-own-footprint and mounted-model-to-board registration, signed-side occupancy, F.Fab/model center and envelope comparisons, and source-envelope/courtyard containment. The fuse's visual terminal bands cannot substitute for land checking.

Finally, run same-camera bare/populated top and bottom renders, populated-minus-bare body extraction, per-ref measured-center deltas, explicit relocation/reopen checks, and a human overlay review for all nine refs. Preserve the generated `missing_models.txt`; prohibit denominator shrinkage. Keep the JLC uploader/assembly preview as an unresolved order-time hold: these parts and the board remain **DO NOT ORDER** until the uploader preview independently confirms exact MPN/code, package/orientation, availability, and every other order gate. No existing threshold is lowered and no physical check is waived by this proposal.
