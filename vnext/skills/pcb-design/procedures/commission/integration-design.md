# Close a candidate interface

Use while commissioning when individually researched blocks still lack a
coherent connection, startup sequence or whole-system budget. Select one
named boundary and one report; do not reopen the entire part search. This is
design research, not architecture admission, part freeze or CAD generation.

Read the brief, current interface candidates and cited manufacturer facts for
both endpoints. Record exact input identities. Choose designer-owned values,
connections and configuration explicitly; do not present missing external
equipment facts as choices the designer can silently make.

For the selected boundary, give an implementable connection/value table,
operating and off-state behavior, limiting conditions and failure disposition.
Digital interfaces need pin directions, voltage compatibility, timing/clock
ownership, reset/straps and supplied firmware configuration. Power boundaries
need aggregate load, sequencing, backfeed and fault coverage. Cable boundaries
need actual conductor/connector mapping, return/shield decisions and the stated
environmental protection scope. Outdoor exposure is not assumed. Load only the
applicable branch of this guidance.

Label guarantees, typical values, bounded assumptions and unknowns separately.
An unresolved critical interface is not closed by a nominal calculation.
Identify the evidence needed before schematic acceptance separately from
prototype qualification: a known contradiction requires repair now; unmeasured
performance may have a later validation owner if the circuit is coherent and
the acceptance contract permits that deferral. Do not waive a requirement.

Independent review rederives the selected interface from primary sources and
checks cross-block consistency on exact report bytes. Record residual risks
and the next discriminating action. Use the existing project binding's attempt
and one-repair limits. Preserve upstream candidates until their replacements
are independently checked; a faithful report can still have an unresolved
engineering disposition.
